# Airduct — Four Landing Page Concepts

A React + Vite + TypeScript workspace containing four independently styled, full-length Airduct landing-page concepts:

- `/architectural` — warm architectural editorial
- `/airflow-lab` — dark technical airflow aesthetic
- `/clear-living` — bright residential-friendly style
- `/field-notes` — bold editorial layout

Each landing page includes Home/Hero, About, Why Cleaning Matters, Services, Why Choose Us, Cleaning Process, Service Standards, Reviews (review-ready; no fabricated testimonials), FAQs, Estimate/Contact, and Footer.

## Run locally

```bash
npm install
npm run dev
```

Estimate form currently validates in the browser only; no submission backend is configured. Photographs use remote Unsplash URLs and require internet access.

## Stack

React, TypeScript, Vite, GSAP, ScrollTrigger, Lenis, Lucide React.

Business claims and imagery should be reviewed before production launch. No invented certifications, ratings, testimonials, or medical guarantees.
